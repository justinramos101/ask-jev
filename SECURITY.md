# Report a vulnerability

Report security issues through [GitHub private vulnerability reporting](https://github.com/justinramos101/ask-jev/security/advisories/new). Include the affected revision, steps to reproduce the issue, and its impact. Remove real credentials from examples.

Do not post secrets or unpatched vulnerabilities in public issues. If you expose an API key, revoke it with the provider before you remove it from files or Git history.

Use the latest version on `main` for security fixes. Older revisions do not receive separate patches.
